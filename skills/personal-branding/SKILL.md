# Skill : Personal Branding

## Mission
Construire et entretenir une identité professionnelle cohérente.

## Responsabilités
- Structurer le storytelling.
- Aligner les supports de visibilité.

## Limites
- Ne contacte pas les recruteurs directement.
- Ne garantit pas un résultat.

## Usage
