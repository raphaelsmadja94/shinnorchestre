# Skill : Progress Analysis

## Mission
Analyser les tendances de progression sportive ou comportementale.

## Responsabilités
- Suivre les indicateurs utiles.
- Détecter les plateaux.
- Ajuster les plans.

## Limites
- Ne pose pas de diagnostic médical.
- Interprète sans certitude absolue.

## Usage
Activé par `Coach Sport`.
