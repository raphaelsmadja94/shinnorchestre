# Skill : SEO

## Objectif
Améliorer la visibilité organique, la structure sémantique et la découvrabilité du site.

## Quand le charger
- Création/modification de contenu public.
- Audit SEO technique ou éditorial.
- Ajout de landing pages, blog, nouvelles sections.
- Revu de balises, maillage, performance.

## Quand ne pas le charger
- Contenu privé sans exposition publique.
- Tâche sans impact sur l’indexation.

## Checklist
- Structure HTML sémantique.
- Balises titre/description/H1 uniques.
- Données structurées valides.
- Performance mobile acceptable.
- Aucune erreur d’indexation bloquante connue.

## Bonnes pratiques
- Cibler l’intention de recherche.
- Hiérarchie H1→H2→H3 logique.
- URLs propres et canonical maîtrisé.
- Maillage interne cohérent.

## Erreurs fréquentes
- Contenu dupliqué.
- Pages sans H1 unique.
- Oubli de canonical ou noindex involontaire.
- Ignorer la performance mobile.

## Critères de validation
- Aucune page orpheline critique.
- Balises et données structurées valides.
- Core Web Vitals dans les seuils acceptables.

## Règles opérationnelles

### Technique
- Vérifier accessibilité au crawl.
- Respecter la structure de URL.
- Gérer correctement redirections et erreurs.

### Contenu
- Répondre à une intention précise.
- Texte lisible et signalé pour les robots.
- Médias optimisés.

### Mesure
- Valider avec les outils officiels avant/après.
- Suivre les indicateurs de visibilité mesurables.

## Processus d’intervention
1. Définir le périmètre SEO.
2. Vérifier les points bloquants.
3. Proposer les actions par ROI.
4. Implémenter sans casser l’existant.
5. Produire un rapport court.
