# Project : shinno

## Contexte
Projet applicatif ShinNO SaaS : site public + back-office studio.

## Objectifs
- Maintenir la plateforme.
- Ajouter des fonctionnalités produit.
- Améliorer la sécurité et la qualité.

## Périmètre connu
- Frontend Angular.
- Backend Spring Boot.
- Stripe partiellement utilisé mais code commenté.
- Book access flow fonctionnel en partie.
- Brevo newsletter.
- Google Calendar.

## Informations manquantes

- CRM et métriques actuels.
- Backlog priorisé complet.
- Plan de test E2E complet.
