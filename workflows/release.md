# Workflow : Release

## Déclencheur
- Mise en production d’une version validée.
- Demande CTO.

## Étapes
1. Vérifier l’état de la branche.
2. Lancer les tests.
3. Construire l’artefact.
4. Déployer selon le runbook.
5. Confirmer la supervision post-release.

## Gouvernance
- Interdit sans validation CTO.
- Rollback possible si incident.

## Format de rapport
- Diagnostic.
- Plan exécuté.
- Commandes.
- Résultats.
- Risques résiduels.
- Décision attendue.
