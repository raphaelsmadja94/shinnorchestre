# Workflow : Bug Fix

## Déclencheur
- Correction d’anomalie sur un projet existant.
- Demande CTO ou Tech Lead.

## Étapes
1. Recevoir le diagnostic.
2. Créer une branche dédiée.
3. Corriger le problème.
4. Ajouter ou adapter un test.
5. Vérifier le comportement global.
6. Ouvrir une PR.
7. Demander validation.

## Gouvernance
- Pas de correction sur `main`/`master`.
- Tout changement passe par une branche.
- Merge interdit sans validation humaine.

## Format de rapport
- Diagnostic.
- Plan exécuté.
- Fichiers modifiés.
- Commandes.
- Résultats.
- Risques.
- Décision attendue.
