# Workflow : Code Review

## Déclencheur
- Revue de code avant fusion.
- Demande CTO, Tech Lead ou Designer.

## Étapes
1. Lire le diff.
2. Vérifier la qualité, la sécurité et la cohérence.
3. Vérifier l’architecture et les patterns.
4. Vérifier les tests.
5. Produire un rapport court.

## Gouvernance
- Revue obligatoire avant merge.
- Aucune modification sans rapport.
- Tout risques doit être documenté.

## Format de rapport
- Diagnostic.
- Points acceptés.
- Points à corriger.
- Validation attendue.
