# Workflow : Rollback

## Déclencheur
- Incident en production nécessitant un retour arrière.
- Demande CTO.

## Étapes
1. Confirmer l’incident.
2. Prévenir les acteurs.
3. Restaurer la version précédente.
4. Vérifier la stabilité.
5. Documenter la cause racine.

## Gouvernance
- Interdit sans validation CTO.
- Traçabilité obligatoire.

## Format de rapport
- Diagnostic.
- Plan exécuté.
- Commandes.
- Résultats.
- Risques résiduels.
- Décision attendue.
