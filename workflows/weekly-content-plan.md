# Workflow : Weekly Content Plan

## Déclencheur
- Planification éditoriale hebdomadaire.
- Demande Growth ou Content Creator.

## Étapes
1. Analyser les performances de la semaine.
2. Définir les sujets.
3. Répartir les formats et canaux.
4. Valider le plan avec les experts concernés.
5. Produire le calendrier.

## Gouvernance
- Plan validé avant production.
- Aucune publication sans validation humaine.

## Format de rapport
- Diagnostic.
- Plan éditorial.
- Formats.
- Validation attendue.
