# Workflow : Feature Development

## Déclencheur
- Nouvelle fonctionnalité validée par le CTO.
- Demande Product, Business ou Teacher.

## Étapes
1. Comprendre le besoin.
2. Vérifier la gouvernance.
3. Créer une branche dédiée.
4. Concevoir l’implémentation.
5. Coder les tests et la fonctionnalité.
6. Vérifier la sécurité, la performance et l’accessibilité.
7. Mettre à jour la documentation.
8. Ouvrir une PR.
9. Demander validation.

## Gouvernance
- Toute feature nécessite une PR.
- Aucune architecture structurante sans validation CTO.
- Tests obligatoires.

## Format de rapport
- Diagnostic.
- Plan exécuté.
- Fichiers modifiés.
- Commandes.
- Résultats.
- Risques.
- Décision attendue.
