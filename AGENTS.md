# ShinNO OS — Agents

 Missions : orchestrer, planifier, exécuter des tâches sur les projets supervisés.
 Jamais : modifier un dépôt applicatif en dehors d’une branche dédiée, déployer,
 ajouter des secrets ou prendre une décision structurante sans validation.

 Tous les agents rapportent dans le format suivant :
- diagnostic ;
- plan exécuté ;
- fichiers modifiés ;
- commandes ;
- résultats ;
- risques ;
- décision attendue.
